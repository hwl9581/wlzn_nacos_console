## 问题和修复

已安装 1.0.1 的环境使用 8848 服务端口。只读探测确认该服务的 `/nacos/v3/console/cs/config/list` 返回 404，Admin 对应路径存在；旧 `/nacos/v1/cs/configs` 返回 410。1.0.1 的 Console → v1 回退遗漏了 Admin API。

1.0.2 在每个上下文中按 Console → Admin → legacy 探测只读列表，仅 HTTP 404/410 尝试下一候选。列表验证成功后，详情和发布固定使用该路由；首次发布先只读探测，正文仅 POST 一次。裸地址兼容同端口根上下文；显式上下文不切换路径，所有候选保持原协议、主机及端口。

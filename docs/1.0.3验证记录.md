# 1.0.3 界面与历史对比验证

日期：2026-10-28。

## 变更

- 按已确认设计整理配置源/环境工具栏、左侧 Data ID/Group 列表及右侧编辑工作区，沿用既有品牌图标。
- 用 IDEA 原生内存编辑器替换 JTextArea，支持语法高亮、行号、缩进线、软换行和编辑器配色。YAML 原生词法解析保留，仅将注释 token 映射到普通行注释配色，避免注释与字符串同色；不改全局颜色方案。
- 远端载入时创建新内存文档、释放旧 Editor，隔离跨配置撤销；格式切换保留正文和光标。搜索保留仍选中的草稿；显式刷新同步远端格式。
- 增加历史版本只读分页窗口：单版本与打开窗口时的当前编辑快照对比，或两个历史版本互相比对。IDEA 原生 Diff 双侧只读，不执行回滚/发布。
- 历史查询使用已探测的 v3 Console/Admin 路由；旧服务优先 v2，仅在 404/410 时尝试 v1。历史详情固定接口族。列表和详情校验版本 ID、Data ID、Group、Namespace；旧 public 记录缺失 tenant 仅归 public，不能匹配自定义 Namespace。

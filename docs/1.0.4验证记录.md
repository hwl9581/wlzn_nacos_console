# 1.0.4 发布 Token 过期修复

日期：2026-10-29。

## 问题与修复

用户在 `/nacos/v3/admin/cs/config` 发布配置时收到 HTTP 403，服务端明确返回 `token expired`。此前连接和列表刷新会重新登录，但发布使用连接时缓存的 Token，长时间打开插件后可能过期。

本次仅修改发布流程：用户确认后，在后台用该连接已有的用户名和密码重新登录，使用新返回的 Token 发起原有配置发布；认证失败或只读路由探测失败时不发送配置正文。配置 POST 不自动重试，403/500 等失败保留当前草稿。认证过程中关闭面板或连接编号改变时停止后续发布，缓存更新和完成回调也检查连接编号。

不改变 Nacos 配置接口族、目标环境、Data ID、Group、Namespace、正文或发布确认步骤，不新增凭据存储。
